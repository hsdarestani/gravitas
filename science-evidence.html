STATISTICAL CORE

Not a black box.

Each synthetic effect is tested using a newly sampled standard normal noise term. When the null is true, the test's nominal Type I error is α.

Z = θ · √n + ε,   ε ~ N(0,1)p = 2[1 − Φ(|Z|)]PPV = π·power / [π·power + (1−π)·α]

Here θ is the assumed effect (zero if the hypothesis is false), n is sample size, π is the assumed prior truth probability and Φ is the standard-normal CDF.
