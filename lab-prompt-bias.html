Challenge

Reduce agreeability and increase evidence checking. Repeat with the same seed, then switch the seed. Which changes are from your assumptions, and which are simulated sampling variation?

Question framing is one factor. A scientifically valid test of actual AI requires real model calls, a prespecified dataset, controlled settings, independent ground-truth evaluation and multiple runs.

How this simulator works

For each condition the engine applies a logistic agreement probability. Leading wording increases an illustrative agreeability term; evidence checking reduces it. Every paired trial uses the same seeded uniform random value under both conditions, isolating framing in this toy world.

The formula is a pedagogical assumption, not a fitted empirical model. Export includes the seed, assumptions and results. Future real-AI evaluations must use a separate rate-limited, auditable experiment service.
