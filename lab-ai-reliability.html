Experimental controls and limitations

A: direct generation. B: same model and question with Europe PMC retrieval. C: human assessment of the same B output, preserving every original reference. Conditions run in randomized order. Temperature 0.2, maximum 1,600 output tokens per response. No hidden provider fallback or automatic request retries.

This is an exploratory convenience sample. References within one response are dependent. Registry metadata does not prove claim support. Europe PMC coverage favors biomedical literature. No pooled confidence intervals or generalizable causal conclusions are reported. Model outputs are nondeterministic; repeating a protocol may produce different observations.

At most 10 model calls per run. Provider charges may apply. Each run has a $0.50 estimated cost ceiling using operator-configured model rates. Execution is blocked without pricing. Estimates are not billing confirmation. Do not enter confidential evidence into a model without authorization.
