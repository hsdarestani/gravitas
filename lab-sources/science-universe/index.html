Read the model before reading the result.

Science Universe is an educational, seeded agent-based model—not a measured model of the global scientific system. It does not run any real AI model or access scientific papers. Agent decisions, hypothesis ground truth, review error rates, statistical power, funding and citation attention are explicitly synthetic assumptions.

Each hypothesis has a hidden Boolean ground truth. Positive study results are sampled using a configurable type-I error rate and an illustrative detection-probability function dependent on signal and sample size. Peer reviewers can miss errors. Replication is an independent stochastic test. Failed replication does not logically prove a finding false; the model's retraction rules are simplified policies.

Agent counts, papers, false claims, queues and citations are calculated outcomes of the same deterministic state transitions. Parallel worlds share a snapshot but diverge under changed policies. One seeded example cannot establish empirical causation or real-world rates.

This is designed to teach questions about AI reliability, verification bottlenecks, incentives and uncertainty, not to settle them. Scientific calibration and external review would be required before empirical interpretation.
