# Source library

Each source is stored as an individual Markdown record so research can be queried, updated and reused without re-reading an unstructured bibliography.

## Required fields

- ID
- title
- authors
- date
- venue
- type
- peer-review status
- canonical URL / DOI
- evidence tier
- claims supported
- important results
- limitations
- editorial use
- verification status
- last checked
