Storage policy

Raw footage, project files and long videos must not be stored on the application server. HQ records metadata and links only.

The Strato application server should run the website, database and HQ — not become a video archive.

Recommended providers

Frame.ioBest for video review, version feedback and editorial approval.
Google DriveGood default for shared working files, documents and exports.
YouTube / VimeoPublished or review video when streaming is the main use case.
Cloudflare R2 / S3Use when we need scalable object storage or programmatic file delivery.

Status

Working is still being edited. Review needs feedback. Approved passed review. Final is the canonical deliverable.

HQ should help the team find the correct file and version. It should not copy the file just to make it “feel centralized”.
