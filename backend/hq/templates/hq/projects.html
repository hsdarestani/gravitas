Use Projects for work that has a meaningful outcome, multiple steps, or more than one person involved.

Example project

Episode 01 — Can AI generate a scientific hypothesis?

That project can contain tasks such as “Build evidence map”, “Review scientific claims”, “Edit rough cut” and “Publish companion page”.

Status meaning

  • Planned: accepted, but not actively being worked on.
  • Active: someone is responsible and work is moving.
  • Blocked: progress cannot continue without a decision, dependency or input.
  • Done: the intended outcome has been delivered.

Keep the board useful

Tasks should be specific actions. If a task is vague enough that two people would interpret it differently, rewrite it.
