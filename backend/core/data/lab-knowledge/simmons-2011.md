# False-Positive Psychology · reading note

Source: https://doi.org/10.1177/0956797611417632

Authors: Joseph P. Simmons, Leif D. Nelson, Uri Simonsohn (2011).

This is an original GraviQuest reading note, not the paper's full text.

## Researcher degrees of freedom

Choosing analyses after seeing results creates opportunities to report a favorable result. Trying several alternatives and reporting only the significant one can inflate false positives.

## A closer look at flexibility in sample size

Repeatedly checking for significance while collecting more observations changes error rates. A fixed single-test threshold does not automatically correct optional stopping.

## Solution

The paper proposes clearer disclosure of collection and analysis decisions so readers and reviewers can assess the evidence.
