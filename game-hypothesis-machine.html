Hypothesis Machine

A hidden rule decides whether a set of three numbers is admitted. Find the rule. You may run as many tests as you like — the interesting question is which ones you choose.

Rule status: unknown Tests run: 0 Confirming: 0 · Falsifying: 0

The machine has admitted 2, 4, 6. Propose another triple and it will tell you whether that one is admitted too.

Why this game exists

Most people test triples they expect to be admitted. That feels like progress and produces almost no information. The rule only becomes visible when you try to break your own guess.

What is being counted

A test is confirming if you expected a yes, and falsifying if you expected a no. The ratio is shown after you commit — it is usually a surprise.
